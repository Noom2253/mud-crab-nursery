# 🦀 สมุดบันทึกอนุบาลลูกปูทะเล

เว็บแอปสำหรับบันทึกการอนุบาลลูกปูทะเลรายวัน ติดตามคุณภาพน้ำ ต้นทุนวัสดุ การจับจำหน่าย และคำนวณกำไร/ขาดทุนของแต่ละรุ่นการผลิต

- **Flask** ไฟล์เดียว (`app.py`) + **Tailwind CSS** (CDN)
- เก็บข้อมูลในฐานข้อมูล **SQLite** (`crab_nursery.db`)

## 1. สิ่งที่ต้องมี

- **Python 3.8 ขึ้นไป**
- **Flask** (ติดตั้งตามขั้นตอนด้านล่าง)
- **อินเทอร์เน็ต** ตอนเปิดหน้าเว็บ เพราะหน้าตาเว็บ (Tailwind) และฟอนต์ภาษาไทยโหลดจากอินเทอร์เน็ต
  ถ้าไม่มีเน็ต ข้อมูลยังบันทึกได้ แต่หน้าเว็บจะไม่มีสีและการจัดวาง

## 2. ติดตั้งและเปิดใช้งาน

### ติดตั้ง Flask (ทำครั้งเดียว)

```bash
pip install flask
```

### เปิดแอป

เปิด Terminal (Command Prompt / PowerShell) ในโฟลเดอร์ที่มีไฟล์ `app.py` แล้วพิมพ์

```bash
python app.py
```

เมื่อขึ้นข้อความ `Running on http://127.0.0.1:5000` ให้เปิดเบราว์เซอร์ไปที่

**http://127.0.0.1:5000**

### ปิดแอป

กด **Ctrl + C** ในหน้าต่าง Terminal

> 💡 **แนะนำให้รันจาก Terminal มากกว่า IDLE**
> รันจาก IDLE (กด F5) ได้เหมือนกัน แต่ข้อความบางบรรทัดอาจไม่แสดง และเมื่อปิด IDLE
> เซิร์ฟเวอร์อาจยังค้างทำงานอยู่เบื้องหลัง (ดูวิธีแก้ในหัวข้อ [แก้ปัญหา](#7-แก้ปัญหาที่พบบ่อย))

## 3. เริ่มใช้งานครั้งแรก

ทำตามลำดับนี้ครั้งเดียว:

1. **⚙️ ตั้งค่าราคา/เกณฑ์**
   - ใส่ **ราคาต่อหน่วยของวัสดุ** ทุกรายการ ถ้าไม่ใส่ ระบบจะไม่นำวัสดุนั้นไปคิดต้นทุน
   - ตรวจ **ราคาจำหน่ายตามขนาด** และ **เกณฑ์คุณภาพน้ำ** ให้ตรงกับของหน่วยงาน
   - (ไม่บังคับ) ใส่ **ชื่อหน่วยงาน** และ **โลโก้**
2. **🦀 รุ่นการผลิต** → สร้างรุ่นแรก (รหัสรุ่น วันที่ฟัก จำนวนเริ่มต้น)
3. **📝 บันทึกประจำวัน** → เริ่มบันทึกได้เลย

## 4. วิธีใช้แต่ละแท็บ

### 📝 บันทึกประจำวัน

บันทึกข้อมูลของแต่ละบ่อ/ถังในแต่ละวัน แบ่งเป็น 5 ส่วน:

| ส่วน | ข้อมูลที่บันทึก |
|---|---|
| ข้อมูลทั่วไป | วันที่ เวลา **รุ่น\*** **บ่อ/ถัง\*** ผู้บันทึก ระยะพัฒนาการ (ซูเอีย 1–5, เมกาโลปา, C1–C4+) |
| คุณภาพน้ำ | อุณหภูมิ ความเค็ม pH DO แอมโมเนีย ไนไตรท์ ความเป็นด่าง การเปลี่ยนน้ำ สีน้ำ สภาพพื้น |
| วัสดุ อาหาร และสาร | ปริมาณวัสดุที่ใช้วันนี้ ความหนาแน่นโรติเฟอร์/อาร์ทีเมีย จำนวนมื้อ การกินอาหาร |
| จำนวนและสุขภาพ | จำนวนคงเหลือโดยประมาณ จำนวนตาย การลอกคราบ การกินกันเอง ความกว้างกระดอง อาการผิดปกติ |
| การจัดการ | สาร/ยาที่ใช้ งานอื่น ๆ หมายเหตุ |

\* = ต้องกรอก

**ระบบช่วยอัตโนมัติ**
- เลือกรุ่นแล้วระบบจะคำนวณ **อายุหลังฟัก**, **อัตรารอด** และ **ต้นทุนวัสดุ (วันนี้ / สะสมทั้งรุ่น)** ให้ทันที
- ช่องคุณภาพน้ำ **เปลี่ยนสี** ตามเกณฑ์ที่ตั้งไว้
  🟢 อยู่ในเกณฑ์ · 🟡 ควรเฝ้าระวัง · 🔴 นอกเกณฑ์
- หลังบันทึก ระบบจำรุ่น บ่อ และผู้บันทึกไว้ให้ ถ้าจะบันทึกบ่อถัดไปในรุ่นเดียวกัน กรอกเฉพาะค่าที่ต่างกันก็พอ
- ช่องบ่อและผู้บันทึกจะแสดงรายชื่อที่เคยกรอกไว้ให้เลือก

### 🦀 รุ่นการผลิต

- **เพิ่มรุ่น**: รหัสรุ่น (ห้ามซ้ำ) วันที่ฟัก จำนวนเริ่มต้น ชนิดปู สถานะ และ **ต้นทุนอื่นของรุ่น** (เช่น แม่พันธุ์ ค่าไฟ ค่าแรง)
- **การ์ดรุ่น** แสดงอัตรารอดล่าสุด ระยะล่าสุด ต้นทุนรวม ยอดขาย และกำไร/ขาดทุน
- ปุ่มบนการ์ด: ✏️ แก้ไข · 📊 ไปหน้าสรุป · 💰 ไปหน้าจับจำหน่าย · 🗑️ ลบ

> ⚠️ **ลบรุ่นแล้ว บันทึกประจำวันและการจับจำหน่ายทั้งหมดของรุ่นนั้นจะถูกลบไปด้วย และกู้คืนไม่ได้**

**ชนิดปูที่เลือกได้**: ปูดำ (*S. olivacea*) · ปูเขียว (*S. serrata*) · ปูม่วง (*S. tranquebarica*) · ปูขาว (*S. paramamosain*) · ไม่ระบุ

### 💰 จับจำหน่าย

1. เลือก **วันที่** และ **รุ่น**
2. เลือก **บ่อ/ถัง** ถ้าจับเฉพาะบ่อ หรือเลือก "ทั้งรุ่น"
3. กรอก **จำนวนที่จับได้แยกตามขนาด** ราคาดึงมาจากหน้าตั้งค่า แก้เฉพาะครั้งนี้ได้
4. ดู **ผลการประเมิน** รายได้ ต้นทุน กำไร/ขาดทุน ต้นทุนต่อตัว จำนวนที่ต้องขายให้คุ้มทุน
5. กด **💰 บันทึกการจับ**

ด้านล่างมีตารางประวัติการจับทั้งหมด แก้ไข ✏️ หรือลบ 🗑️ ได้

### 📋 ประวัติ

- ตารางบันทึกประจำวันทั้งหมด **ค้นหา** ได้ตามบ่อ ผู้บันทึก หมายเหตุ และ **กรอง** ตามรุ่นหรือช่วงวันที่
- กด **ดู** เพื่อเปิดรายละเอียด หรือกด ✏️ เพื่อแก้ไข (การลบทำได้จากหน้าต่างรายละเอียด)
- ปุ่มเครื่องมือ:
  - **⬇️ ส่งออก CSV (Excel)**: ส่งออก**เฉพาะรายการที่กรองอยู่** เปิดใน Excel แล้วภาษาไทยแสดงถูกต้อง
  - **💾 สำรองข้อมูล (JSON)**: ดาวน์โหลดข้อมูลทั้งหมด (ดูหัวข้อ 6)
  - **📂 นำเข้าข้อมูลสำรอง**: นำไฟล์ JSON กลับเข้าระบบ
  - **🖨️ พิมพ์**

### 📊 สรุปต้นทุน-กำไร

เลือกรุ่นที่ต้องการ หรือเลือก "ทุกรุ่น" เพื่อดูภาพรวม
- **ตัวเลขสรุป**: อายุ อัตรารอด คงเหลือ ค่าน้ำเฉลี่ย จำนวนครั้งที่น้ำนอกเกณฑ์ ต้นทุน รายได้ กำไร/ขาดทุน
- **ตารางวัสดุสะสม**: ปริมาณที่ใช้ของแต่ละวัสดุ × ราคา = ต้นทุน
- **กราฟอัตรารอดตามอายุ** (ต้องเลือกรุ่นก่อน)
- **กราฟคุณภาพน้ำ** แยกพารามิเตอร์ แถบสีเขียวคือช่วงเหมาะสม จุดมีสีตามสถานะ

### ⚙️ ตั้งค่าราคา/เกณฑ์

แก้ไขแล้ว **บันทึกอัตโนมัติ** ไม่ต้องกดปุ่มบันทึก

| ส่วน | รายละเอียด |
|---|---|
| ข้อมูลหน่วยงาน | ชื่อหน่วยงาน หน่วยงานย่อย โลโก้ (ปรับขนาดด้วยแถบเลื่อน) พื้นหลังวงกลม |
| วัสดุและราคาต่อหน่วย | เพิ่ม/แก้/ลบ วัสดุ หมวด หน่วย ราคา |
| ราคาจำหน่ายตามขนาด | เพิ่ม/แก้/ลบ ขนาดและราคาต่อตัว |
| เกณฑ์คุณภาพน้ำ | ช่วงเหมาะสม (เขียว) และช่วงเฝ้าระวัง (เหลือง) ของแต่ละค่า กด ↺ เพื่อคืนค่าเริ่มต้น |

**เกณฑ์คุณภาพน้ำเริ่มต้น**

| พารามิเตอร์ | เหมาะสม (🟢) | เฝ้าระวัง (🟡) |
|---|---|---|
| อุณหภูมิ (°C) | 27.5 – 29.5 | 26.5 – 30.5 |
| ความเค็ม (ppt) | 27 – 29 | 25 – 31 |
| pH | 7.7 – 7.9 | 7.5 – 8.1 |
| DO (mg/L) | 6 – 8.5 | 5 – 9.5 |
| แอมโมเนียรวม TAN (mg/L) | ไม่เกิน 0.2 | ไม่เกิน 0.3 |
| ไนไตรท์ (mg/L) | ไม่เกิน 0.3 | ไม่เกิน 0.5 |
| ความเป็นด่าง (mg/L) | 100 – 120 | 90 – 130 |

ค่าที่อยู่นอกช่วงเฝ้าระวังจะเป็น 🔴 นอกเกณฑ์

## 5. การคำนวณในระบบ

| รายการ | สูตร |
|---|---|
| อายุหลังฟัก (วัน) | วันที่บันทึก − วันที่ฟัก |
| อัตรารอด (%) | จำนวนคงเหลือ ÷ จำนวนเริ่มต้นของรุ่น × 100 |
| ต้นทุนวัสดุ | Σ (ปริมาณที่ใช้ × ราคาต่อหน่วย) |
| ต้นทุนการผลิตรวม | ต้นทุนวัสดุทั้งรุ่น + ต้นทุนอื่นของรุ่น |
| รายได้ | Σ (จำนวนที่จับ × ราคาต่อตัว) |
| กำไร/ขาดทุน | รายได้ − ต้นทุนการผลิตรวม |
| ต้นทุนต่อตัว | ต้นทุนการผลิตรวม ÷ จำนวนที่จับได้ทั้งหมด |
| จำนวนที่ต้องขายให้คุ้มทุน | ต้นทุนการผลิตรวม ÷ ราคาขายเฉลี่ย (ปัดขึ้น) |

**ข้อควรรู้**
- ต้นทุนวัสดุคิดจาก **ราคาปัจจุบันในหน้าตั้งค่า** ถ้าแก้ราคา ต้นทุนย้อนหลังทั้งหมดจะเปลี่ยนตาม
- วัสดุที่ **ยังไม่ใส่ราคา** หรือ **ถูกลบ** จะไม่ถูกนำไปคิดต้นทุน
- ถ้าเลือกดูการจับ **เฉพาะบ่อ** ระบบคิดเฉพาะต้นทุนวัสดุของบ่อนั้น ไม่รวมต้นทุนอื่นของรุ่น

## 6. สำรองและย้ายข้อมูล

### ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดอยู่ในไฟล์ **`crab_nursery.db`** ในโฟลเดอร์เดียวกับ `app.py`
**ถ้าไฟล์นี้หาย ข้อมูลจะหายทั้งหมด** ควรสำรองเป็นประจำ

### วิธีสำรอง (เลือกได้)

1. **คัดลอกไฟล์ `crab_nursery.db`** ไปเก็บที่อื่น เช่น Google Drive หรือแฟลชไดรฟ์ ควรปิดแอปก่อนคัดลอก
2. **กด 💾 สำรองข้อมูล (JSON)** ในแท็บประวัติ ได้ไฟล์ `crab-nursery-backup-วันที่.json` ที่มีรุ่น บันทึก การจับ การตั้งค่า ชื่อหน่วยงาน และโลโก้ครบ

### วิธีกู้คืน / นำเข้า

แท็บ **📋 ประวัติ** → **📂 นำเข้าข้อมูลสำรอง** → เลือกไฟล์ `.json`
- ระบบ **รวม** ข้อมูลในไฟล์เข้ากับข้อมูลเดิม ไม่ได้ลบของเดิม ถ้ารายการไหนมีอยู่แล้ว จะใช้ค่าจากไฟล์แทน
- ระบบจะถามว่าจะใช้การตั้งค่า (ราคาวัสดุ ราคาขาย เกณฑ์น้ำ) จากไฟล์ด้วยหรือไม่

### ย้ายข้อมูลจากไฟล์ HTML เวอร์ชันเดิม

ถ้าเคยใช้ `crab-nursery-log.html` (เวอร์ชันที่เก็บข้อมูลในเบราว์เซอร์):
1. เปิดไฟล์ HTML เดิม → แท็บประวัติ → กด **💾 สำรองข้อมูล (JSON)**
2. เปิดแอปนี้ → แท็บประวัติ → กด **📂 นำเข้าข้อมูลสำรอง** → เลือกไฟล์ที่ได้

ชื่อชนิดปูแบบเดิมจะถูกแปลงเป็นชื่อปัจจุบันให้อัตโนมัติ (ปูทองหลาง → ปูดำ, ปูดำ → ปูเขียว)

### ย้ายไปใช้เครื่องอื่น

คัดลอก `app.py` และ `crab_nursery.db` ไปไว้ในโฟลเดอร์เดียวกันบนเครื่องใหม่ ติดตั้ง Flask แล้วรันได้เลย

| เปิดเว็บขึ้นแถบเหลือง "โหลดข้อมูลจากเซิร์ฟเวอร์ไม่สำเร็จ" | แอปไม่ได้รันอยู่ ให้รัน `python app.py` ใหม่ |
| ต้นทุนเป็น 0.00 | ยังไม่ได้ใส่ราคาวัสดุในแท็บตั้งค่า |

**ปิดเซิร์ฟเวอร์ที่ค้างอยู่** (มักเกิดหลังรันจาก IDLE แล้วปิดหน้าต่าง):

```bash
taskkill /F /IM pythonw.exe
```

คำสั่งนี้จะปิดหน้าต่าง IDLE ที่เปิดอยู่ทั้งหมดด้วย ถ้ารันจาก Terminal ให้เปลี่ยนเป็น `python.exe`

## 8. ข้อควรระวังด้านความปลอดภัย

แอปนี้ออกแบบมาให้ **ใช้บนเครื่องตัวเองเท่านั้น** (เปิดได้ที่ `127.0.0.1`)

- **ไม่มีระบบล็อกอิน** ใครเปิดหน้าเว็บได้ ก็แก้ไขหรือลบข้อมูลได้ทั้งหมด
- ตอนนี้รันใน **debug mode** ซึ่งปลอดภัยเฉพาะบนเครื่องตัวเอง
  **ห้ามเปิดให้เครื่องอื่นหรืออินเทอร์เน็ตเข้าถึงขณะที่ debug mode ยังเปิดอยู่** เพราะผู้อื่นอาจสั่งรันคำสั่งบนเครื่องของคุณได้

ถ้าต้องการให้มือถือหรือเครื่องอื่นใน Wi-Fi เดียวกันใช้งาน หรือนำขึ้นออนไลน์ ต้องปิด debug mode และเพิ่มระบบล็อกอินก่อน

## 9. โครงสร้างไฟล์

```
website/
├── app.py            # แอปทั้งหมด: เซิร์ฟเวอร์ Flask + หน้าเว็บ + JavaScript
├── crab_nursery.db   # ฐานข้อมูล SQLite (สร้างอัตโนมัติเมื่อรันครั้งแรก)
└── README.md         # ไฟล์นี้
```

**ตารางในฐานข้อมูล**

| ตาราง | เก็บอะไร |
|---|---|
| `batches` | รุ่นการผลิต |
| `logs` | บันทึกประจำวัน |
| `harvests` | การจับจำหน่าย |
| `kv` | การตั้งค่า ข้อมูลหน่วยงาน โลโก้ |
| `records` | ข้อมูลจากแอปเวอร์ชันเก่า (แอปปัจจุบันไม่ได้ใช้) |

**เปลี่ยนตำแหน่งไฟล์ฐานข้อมูล** (ไม่บังคับ): ตั้งตัวแปรสภาพแวดล้อม `CRAB_DB` ก่อนรัน เช่นใน PowerShell

```powershell
$env:CRAB_DB = "D:\backup\crab.db"; python app.py
```
